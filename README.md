# فهرس وموقع قناة رياض الجنة

فهرس وموقع لدروس [قناة رياض الجنة](https://t.me/reyad_elganna) على تليجرام (م. محمود علي).

## ما الموجود هنا
- `site/` الموقع (صفحة واحدة + `data.json` + صور الإعلانات في `p/`).
- `فهرس قناة رياض الجنة.xlsx` الفهرس الكامل بكل الروابط.
- `index/telegram/` منشورات فهرس جاهزة للنشر على القناة.
- `data/author.json` صفحة التعريف بالشيخ (تُعدَّل يدويًا).
- `tools/` السكريبتات:
  - `scrape.py` يقرأ منشورات القناة العامة.
  - `classify.py` و`rules.py` تصنيف المواد (التصحيحات اليدوية في `OVERRIDES` داخل `rules.py`).
  - `posters.py` ربط الإعلانات بالدروس والسلاسل.
  - `build_index.py` ملف الإكسل ومنشورات الفهرس.
  - `build_site.py` بيانات الموقع والنسخة الكاملة في `docs/`.
  - `update_all.py` يشغّلها كلها بالترتيب.

## التحديث التلقائي
ملف `.github/workflows/update.yml` يعمل كل ساعة: يجلب المنشورات الجديدة، ويعيد بناء الفهرس والموقع، وينشره على GitHub Pages. ويعيد قراءة القناة كاملة كل جمعة. يمكن تشغيله يدويًا من تبويب Actions ← Run workflow.

## التشغيل على الجهاز
```bash
pip install beautifulsoup4 pillow openpyxl
python -X utf8 tools/update_all.py
```
